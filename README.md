# Student Portfolio Website

## Project Overview

This project is a responsive Student Portfolio and Academic Management Website developed as part of my academic assignment at MIVA Open University.

The website showcases my personal information, educational background, skills, projects, and provides an interactive academic planner for managing tasks and activities.

The project is designed with a simple, minimalist layout that is easy to navigate and use across different screen sizes.

## Website Features

### 1. Home Page
- Personal introduction and welcome message.
- Navigation menu for accessing different sections.
- Personal photograph.

### 2. About Me
- Educational background.
- Personal information.
- Skills, interests, and hobbies.
- Career aspirations.

### 3. Projects Page
- Displays my projects.
- Includes project descriptions.
- Provides an overview of my development experience.

### 4. Academic Planner
- Add new academic tasks.
- Mark tasks as completed.
- Delete tasks when they are no longer needed.
- Organize academic activities.

## Technologies Used

- **HTML5:** Website structure and content.
- **CSS3:** Styling, layout, and responsive design.
- **JavaScript:** Interactive website features and academic planner functionality.

## How to Run the Website

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Navigate through the website using the navigation menu.
